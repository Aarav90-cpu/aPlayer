# Credits

aPlayer uses several open-source libraries and components to function properly. We would like to express our gratitude to the developers and communities behind these projects:

### Core Dependencies
- **[libvlc](https://www.videolan.org/vlc/libvlc.html)**: The C library at the heart of VLC media player, used for handling robust audio playback.
- **[pywebview](https://pywebview.flowrl.com/)**: A lightweight cross-platform wrapper around a webview component that allows displaying HTML content in its own native GUI window.
- **[TagLib](https://taglib.org/)**: Used in the C core (`tag_c`) to read audio metadata (ID3, FLAC, Ogg tags).
- **[cJSON](https://github.com/DaveGamble/cJSON)**: Lightweight JSON serialization logic used in the C backend to build the catalog.

### UI Dependencies
- **[Material Web Components](https://github.com/material-components/material-web)**: Google's official Material Design 3 Web components.
- **[Material Symbols](https://fonts.google.com/icons)**: Official Material Design icons.
- **[Lit](https://lit.dev/)**: A simple library for building fast, lightweight web components (used by Material Web).
